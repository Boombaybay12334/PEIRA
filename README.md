# PEIRA

PEIRA is a research-and-writing site for long-form essays with interactive toolkit modules.
The site is built with Astro and will publish static content through Cloudflare Pages.

## Development

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Run the foundation checks with:

```sh
pnpm check
pnpm build
```

Project decisions and sprint requirements are documented in [`docs/`](docs/).
