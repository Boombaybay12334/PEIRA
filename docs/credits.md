# Credits

## Fonts

PEIRA bundles these self-hosted Fontsource variable font packages. Each package
declares the SIL Open Font License 1.1 in its package metadata:

- Newsreader — `@fontsource-variable/newsreader`, https://fontsource.org/fonts/newsreader
- Fraunces — `@fontsource-variable/fraunces`, https://fontsource.org/fonts/fraunces
- JetBrains Mono — `@fontsource-variable/jetbrains-mono`, https://fontsource.org/fonts/jetbrains-mono
